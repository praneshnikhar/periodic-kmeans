About this explorer

The study asks whether K-Means, given only six bulk properties, recovers the periodic table's 18 families. It does not: the adjusted Rand index at k* = 5 is 0.0164 on the 90 labeled elements. It does recover the coarser s/p/d/f blocks, weakly but detectably.

The explorer is a static page. scripts/ui_data.py exports the fitted labels, centroids, PCA coordinates, and validation metrics into data.js; the browser only reads that file. No chemistry label enters the feature matrix, and no result is recomputed in the browser.

Data: mendeleev 1.3.0 snapshot, 118 elements. Method: median imputation and standardization inside a scikit-learn pipeline, K-Means with n_init=10, seeds 0–2 for the study; the explorer shows the seed-0 fit.

Repository: github.com/praneshnikhar/periodic-kmeans. Report: reports/project_report.pdf.
